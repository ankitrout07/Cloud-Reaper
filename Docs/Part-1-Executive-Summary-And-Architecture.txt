1. EXECUTIVE SUMMARY
---------------------
Cloud-Reaper is a next-generation, industrial-grade Hybrid FinOps Intelligence
Engine designed to bridge the structural gap between cloud financial management
(FinOps) and automated engineering action.

Unlike traditional static dashboards that merely report past cloud spend,
Cloud-Reaper actively continuously monitors, models, forecasts, and optimizes
multi-cloud infrastructure. It is designed to act on three main operational
phases of the FinOps framework:
  * Inform Phase (Visibility & High-Performance Auditing): Sub-second resource
    discovery, high-fidelity regional price caching, hierarchical virtual tagging,
    and season-aware anomaly detection.
  * Optimize & GreenOps Phase (Waste & Carbon Mitigation): AI-driven right-sizing
    via Q-learning reinforcement learning, predictive Spot instance eviction
    forecasting, zero-downtime cluster hibernation, grid carbon intensity tracking,
    and a Bounded Knapsack Gemini Copilot for budget-capped architecture generation.
  * Operate Phase (Governance & Guardrails): Automatic "shift-left" cost simulations
    for pull requests, budget deallocation kill-switches, secret credential vaults,
    and Discord integration for automated compliance signaling.


2. THE DUAL-CORE ARCHITECTURE PHILOSOPHY
-----------------------------------------
Cloud-Reaper utilizes a unique hybrid Python + Go design to combine the best
capabilities of both developer ecosystems:

┌──────────────────────────────────────────────────────────────────────────────┐
│                              AZURE SUBSCRIPTION / CLOUD PROVIDERS            │
└──────────────────────────────────────┬───────────────────────────────────────┘
                                       │ (REST / SDK Calls)
┌──────────────────────────────────────▼───────────────────────────────────────┐
│              HIGH-VELOCITY SCANNING CORE (engine-go / Go 1.24+)              │
│  - Concurrently queries Cloud SDK APIs using Goroutines.                     │
│  - Employs token-bucket rate limiters to respect cloud provider quotas.      │
│  - Performs raw data parsing, structural checks, and writes to PostgreSQL.   │
└──────────────────────────────────────┬───────────────────────────────────────┘
                                       │ (PostgreSQL Data Model Bridge)
┌──────────────────────────────────────▼───────────────────────────────────────┐
│              FINOPS INTELLIGENCE & OPTIMIZATION LAYER (Python 3.12+)         │
│  - Ingests telemetry databases and constructs predictive ML pipelines.       │
│  - Performs seasonal ARIMA forecasting & seasonal-decomposition anomalies.   │
│  - Executes Q-learning evaluation for scaling and rightsizing VM pools.     │
│  - Manages AI Copilot logic and structured schema contract validation.        │
└──────────────────────────────────────┬───────────────────────────────────────┘
                                       │ (Flask / Websockets API)
┌──────────────────────────────────────▼───────────────────────────────────────┐
│                     SOCKET.IO REAL-TIME GLASSMORPHISM UI                     │
│  - Renders low-latency operational dashboards (sub-millisecond loads).       │
│  - Streamlines logs and broadcasts budget breach warning frames.             │
└──────────────────────────────────────────────────────────────────────────────┘

* Go Performance Core (engine-go):
  - Written in Go 1.24+ for massive parallel scaling and memory efficiency.
  - Multi-threaded scrapers execute concurrent API queries using lightweight
    Goroutines and sync.WaitGroup worker pool models.
  - Leverages token-bucket rate limiters (`golang.org/x/time/rate`) to strictly
    respect provider API quotas and prevent throttling.
  - Acts as a high-speed database ingestion bridge, writing raw asset snapshots
    directly into PostgreSQL.

* Python FinOps Intelligence Layer (reaper):
  - Written in Python 3.12+ for scientific computing, machine learning, and
    high-level orchestration.
  - Implements rightsizing evaluation using a custom reinforcement learning
    agent, time-series ARIMA predictive models, and statsmodels seasonal
    decomposition.
  - Drives the generative AI Copilot, using Google's modern `google-genai` SDK
    and structured JSON schema output contracts (Pydantic).
  - Handles a thread-safe Flask + Gevent/SocketIO server, serving live telemetry
    updates and managing a production-grade cryptographic credential store.


3. WORKSPACE DIRECTORY STRUCTURE
---------------------------------
The codebase is structured logically to maintain a clean boundary between the
high-velocity Go collector core, the Python intelligence/web layer, and automated
CI/CD developer pathways:

Cloud-Reaper/
├── bin/                       # Compiled high-performance Go binaries (reaper-engine)
├── bootstrap.py               # Universal, one-click cross-platform setup script
├── docker-compose.yml         # Container definitions for PostgreSQL database services
├── Dockerfile                 # Multi-stage production container build manifest
├── Docs/                      # High-fidelity system diagrams, patch updates, and docs
│   ├── Pasted image.png       # Integrated UI reference visual
│   ├── Patch-Updates.txt      # Roadmap item logs and checklist modifications
│   └── Part-*.txt             # Modular multi-part system documentation
├── HOW_TO_RUN.md              # Exhaustive setup, database initialization & run guide
├── main.py                    # Unified CLI command-line interface entry point
├── Makefile                   # Standard developer shortcuts (build, test, lint, format)
├── pyproject.toml             # Configuration parameters for Ruff, Mypy, and Pytest
├── requirements.txt           # Production runtime Python dependencies (grouped by tier)
├── requirements-dev.txt       # Local developer and CI quality control packages
├── scripts/
│   └── reap.sh                # UNIX-compatible shortcut shell script
├── src/
│   ├── engine-go/             # [Go Core] High-velocity parallel scanner module
│   │   ├── collectors/        # Scrapers for AWS, Azure, GCP, and Kubernetes; price clients
│   │   ├── db/                # PostgreSQL low-level integration wrapper (lib/pq)
│   │   ├── go.mod / go.sum    # Dependency management manifest for Go packages
│   │   └── main.go            # Entry point for the Go-compiled performance engine
│   └── reaper/                # [Python Layer] Intelligence and web application
│       ├── collectors/        # Credentials check, AWS/Azure/GCP price client fallbacks
│       ├── engine/            # ML/RL models, ARIMA engines, Pydantic Copilot validation
│       ├── services/          # Log streaming and WebSocket notifications
│       └── web/               # Flask server, blueprints, SQLite/PG vault crypto, templates
└── tests/                     # Multi-tier testing suite (unit, integration, experimental)
