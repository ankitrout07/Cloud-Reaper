# Changelog

Here is the log of our historical and current updates.

## v1.2.0 - The Governance & Compliance Update
*May 20, 2026*
- Introduced Audit Logging for tracking changes to Cost Reports, Virtual Tags, and Segments.
- Integrated Audit Log system guides directly into the RAG Search and Documentation portals.

*May 19, 2026*
- Added System Documentation portal (Product Docs & Changelog).
- Fixed a major bug where generated Bill of Materials incorrectly multiplied flat-rate monthly SKUs by 730 hours.

- Refactored Settings to include a robust "Switch Directory" module, abandoning the static connection fields.

## v1.0.0 - Genesis Release
*May 15, 2026*
- Introduced Cloud Reaper hybrid FinOps engine.
- Launched AI Architect for automated infrastructure design.
- Implemented Go-based resource scraper architecture for maximum efficiency.
- Introduced PostgreSQL caching layer for instantaneous region pricing data.
