## 📋 Getting Started

### Prerequisites
- Cloud provider credentials (AWS, Azure, GCP, or Kubernetes)
- Python 3.12+ (for local development and intelligence layer)
- Go 1.26+ (for high-performance scanner components)
- Docker (for PostgreSQL database container)
- Azure CLI (`az login`) — for Azure scanning

### Installation

#### Method 1: Universal Bootstrap (Recommended)
```bash
# Clone the repository
git clone https://github.com/ankitrout07/Cloud-Reaper.git
cd Cloud-Reaper

# Run the universal bootstrap script
python bootstrap.py
```

The bootstrap script automatically:
- Detects your OS (Windows, macOS, Linux)
- Creates a Python virtual environment
- Installs all dependencies
- Builds the Go performance engine
- Configures PostgreSQL
- Launches the dashboard at http://localhost:5001

#### Method 2: Manual Installation
```bash
# Clone the repository
git clone https://github.com/ankitrout07/Cloud-Reaper.git
cd Cloud-Reaper

# Create Python virtual environment
python3 -m venv venv
source venv/bin/activate  # Windows: venv\Scripts\activate

# Install Python dependencies
pip install -r requirements.txt -r requirements-dev.txt

# Build Go engine
cd src/engine-go
go build -o ../../bin/reaper-engine .
cd ../..

# Start PostgreSQL
docker run --name cloud-reaper-db -e POSTGRES_PASSWORD=postgres -p 5432:5432 -d postgres:15-alpine

# Configure environment variables
cp .env.example .env
# Edit .env with your credentials

# Run the application
PYTHONPATH=src python -m reaper.web.app_async
```

## 🏗️ Architecture Overview

### Components

- **Go Scanner Engine** (`src/engine-go/`): High-performance resource discovery using goroutines with token-bucket rate limiting (10 req/s)
- **Python ML Engine** (`src/reaper/engine/`): Q-learning rightsizing, ARIMA forecasting, anomaly detection, and unit economics
- **FastAPI + SocketIO Backend** (`src/reaper/web/`): RESTful API with WebSocket support for real-time updates
- **Web Dashboard**: Modern glassmorphism UI with real-time charts, metrics, and dark/light theme
- **PostgreSQL 15**: Production-grade database with SQLAlchemy 2.0 ORM and pgx/v5 driver
- **Cryptographic Vault**: PBKDF2-HMAC-SHA256 (600K iterations) + Fernet AES-128-CBC encryption
- **AI Copilot**: Google Gemini 2.5 Flash with structured Pydantic schema validation

### Data Flow

1. **Telemetry Collection**: Go scrapers concurrently collect resource metrics from cloud APIs using goroutines
2. **Database Ingestion**: Raw data is normalized and batch-upserted into PostgreSQL via pgx/v5
3. **Analysis Pipeline**: Python ML engines analyze usage patterns using ARIMA, Q-learning, and statistical models
4. **Storage**: Optimized data is stored in PostgreSQL with 5-minute auto-purge of stale entries
5. **Presentation**: Dashboard displays real-time insights via WebSocket with in-memory cache acceleration
6. **Audit Logging**: Every action is logged to a SHA-256 chained hash ledger for tamper detection

## 🚢 Deployment

### Production Deployment

#### Docker Compose (Recommended)
```bash
# Full-stack deployment: app + PostgreSQL
docker compose up -d
```

This launches:
- **cloud-reaper-db**: PostgreSQL 15 (Alpine) with persistent volume
- **cloud-reaper-app**: Multi-stage build (Go builder → Python 3.12 runtime)

#### Standalone Docker Build
```bash
docker build -t cloud-reaper:latest .
docker run -p 5001:5001 \
  -e DATABASE_URL=postgresql://postgres:postgres@host.docker.internal:5432/cloud_reaper \
  -e AZURE_SUBSCRIPTION_ID=your-sub-id \
  cloud-reaper:latest
```


### Common Issues

**Q: Scanner not finding resources?**
A: Verify cloud provider credentials, check API permissions, and ensure `az login` has been run for Azure.

**Q: Dashboard not updating?**
A: Check WebSocket connection, verify the Go engine is running, and refresh the page.

**Q: Alerts not firing?**
A: Verify webhook URLs in `.env`, check notification service status, and ensure budget thresholds are configured.

**Q: ModuleNotFoundError: reaper?**
A: Set `PYTHONPATH=src` before running Python commands, or use `python -m reaper.web.app_async`.

**Q: Database connection failed?**
A: Ensure PostgreSQL Docker container is running: `docker start cloud-reaper-db`

**Q: Go engine not found?**
A: Build the Go engine: `cd src/engine-go && go build -o ../../bin/reaper-engine . && cd ../..`
