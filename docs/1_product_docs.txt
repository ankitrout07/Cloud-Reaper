## 📋 Getting Started

### Prerequisites
- Cloud provider credentials (AWS, Azure, GCP, or Kubernetes)
- Python 3.8+ (for local development)
- Go 1.18+ (for scanner components)
- Database (SQLite for development, PostgreSQL for production)

### Installation

```bash
# Clone the repository
git clone https://github.com/your-org/cloud-reaper.git
cd cloud-reaper

# Install Python dependencies
pip install -r requirements.txt

# Configure environment variables
cp .env.example .env
# Edit .env with your credentials

# Run the application
python main.py
```

### Initial Configuration

1. **Cloud Provider Setup**: Connect your cloud accounts via the Settings page
2. **Budget Configuration**: Set your monthly spend limits and alert thresholds
3. **Scanner Initialization**: Enable automated resource discovery
4. **Alert Configuration**: Set up notification channels (Discord, Slack, etc.)

## 🏗️ Architecture Overview

### Components

- **Go Scanner Engine**: High-performance resource discovery and telemetry collection
- **Python ML Engine**: Q-learning rightsizing, ARIMA forecasting, and anomaly detection
- **FastAPI Backend**: RESTful API with WebSocket support for real-time updates
- **Web Dashboard**: Modern interface with real-time charts and metrics
- **SQLite/PostgreSQL**: Flexible database backend with connection pooling

### Data Flow

1. **Telemetry Collection**: Go scrapers collect resource metrics from cloud APIs
2. **Analysis Pipeline**: Python ML engines analyze usage patterns and generate recommendations
3. **Storage**: Optimized data is stored in the database for historical analysis
4. **Presentation**: Dashboard displays real-time insights and actionable recommendations

## 🔧 Configuration

### Environment Variables

```bash
# Database
DATABASE_URL=sqlite:///data/reaper.db

# Cloud Providers
AZURE_SUBSCRIPTION_ID=your-subscription-id
AWS_ACCESS_KEY_ID=your-access-key
AWS_SECRET_ACCESS_KEY=your-secret-key
GCP_PROJECT_ID=your-project-id

# AI Integration
OPENAI_API_KEY=your-openai-key
GEMINI_API_KEY=your-gemini-key

# Notifications
DISCORD_WEBHOOK_URL=your-discord-webhook
SLACK_WEBHOOK_URL=your-slack-webhook
```

### Scanner Configuration

Configure scanner behavior via the Settings page:

- **Scan Frequency**: How often to scan your cloud resources
- **Resource Types**: Which resource types to include (VMs, disks, databases, etc.)
- **Regions**: Which cloud regions to scan
- **Thresholds**: Custom CPU/memory utilization thresholds

## 🔒 Security

### Credential Management

Cloud Reaper uses a secure vault for credential storage:

- **AES-128 Encryption**: All credentials are encrypted at rest
- **PBKDF2 Key Derivation**: Secure master passcode verification
- **Role-Based Access**: Configure access controls for different users
- **Audit Logging**: Track all credential access and modifications

### Best Practices

- Use service accounts with minimal required permissions
- Rotate credentials regularly
- Enable audit logging for compliance
- Use environment variables for sensitive configuration
