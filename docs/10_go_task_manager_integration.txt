# Go Task Manager Integration Guide

## Overview
The Cloud-Reaper project now includes a high-performance Go-based background task manager that can replace or augment the existing Python asyncio implementation for enhanced performance.

## Architecture

### Go Components
- **Task Manager Core** (`src/engine-go/internal/background/task_manager.go`)
  - Goroutine-based worker pool pattern
  - Efficient task scheduling and execution
  - Built-in progress tracking and result caching
  - Thread-safe operations with mutex protection

- **HTTP Server** (`src/engine-go/internal/background/server.go`)
  - RESTful API for task management
  - JSON-based communication
  - Support for task submission, status checking, cancellation

- **Task Server Binary** (`src/engine-go/cmd/taskserver/main.go`)
  - Standalone HTTP server process
  - Configurable port (default: 7071)
  - Graceful shutdown handling

### Python Integration
- **Bridge Module** (`src/reaper/engine/core/go_task_manager.py`)
  - Async HTTP client for Go server communication
  - Pythonic interface to Go task manager
  - Automatic fallback to Python backend
  - Seamless integration with existing code

- **Enhanced Background Manager** (`src/reaper/engine/core/background_tasks.py`)
  - Hybrid Python/Go task execution
  - Automatic backend selection
  - Backward compatibility maintained

## Benefits

### Performance Improvements
- **Concurrency**: Go goroutines vs Python asyncio
- **Memory**: Efficient memory management
- **CPU**: Better multi-core utilization
- **Latency**: Lower overhead for task operations

### Features
- **Worker Pool**: Configurable concurrent workers
- **Task Prioritization**: Queue-based execution
- **Progress Tracking**: Real-time progress updates
- **Error Handling**: Robust error recovery
- **Graceful Shutdown**: Clean process termination

## Installation

### Build Go Task Server
```bash
cd src/engine-go
go build -o ../../bin/task-server ./cmd/taskserver/main.go
```

### Start the Server
```bash
# Linux/macOS
./scripts/start_task_server.sh

# Windows
.\scripts\start_task_server.bat

# Or directly
./bin/task-server --port=7071
```

### Environment Variables
```bash
# Optional: Configure Go task manager connection
export GO_TASK_MANAGER_HOST=localhost
export GO_TASK_MANAGER_PORT=7071

# Disable Go backend (fall back to Python)
export USE_GO_TASK_MANAGER=false
```

## Usage

### Python API
```python
from reaper.engine.core.background_tasks import background_manager

# Submit a task (automatically uses Go backend if available)
task_id = await background_manager.submit_task(
    func=my_heavy_computation,
    args=[arg1, arg2],
    task_id="custom_task_id"
)

# Check task status
result = await background_manager.get_task_status(task_id)
print(f"Task status: {result.status}, Progress: {result.progress}")

# Wait for completion
final_result = await background_manager.get_task_status(task_id)
if final_result.status == TaskStatus.COMPLETED:
    print(f"Result: {final_result.result}")
```

### Direct Go API
```python
from reaper.engine.core.go_task_manager import (
    get_task_manager_bridge,
    submit_price_scan,
    submit_resource_audit
)

# Get bridge instance
bridge = get_task_manager_bridge()

# Submit specific task types
task_id = await submit_price_scan(
    subscription_id="your-sub-id",
    regions=["eastus", "westus2"]
)

# Wait for completion
result = await bridge.wait_for_completion(task_id, timeout=300)
```

### HTTP API
```bash
# Submit a task
curl -X POST http://localhost:7071/api/tasks/submit \
  -H "Content-Type: application/json" \
  -d '{
    "task_type": "price_scan",
    "args": ["subscription-id", ["eastus", "westus2"]],
    "metadata": {"subscription_id": "subscription-id"}
  }'

# Check task status
curl http://localhost:7071/api/tasks/{task_id}

# Get all tasks
curl http://localhost:7071/api/tasks

# Cancel a task
curl -X POST http://localhost:7071/api/tasks/cancel/{task_id}

# Get statistics
curl http://localhost:7071/api/tasks/stats
```

## Task Types

### Available Go Task Types
- `price_scan`: Cloud pricing data collection
- `resource_audit`: Resource inventory and compliance checking
- `cost_analysis`: Cost optimization analysis
- `metrics_fetch`: Performance metrics collection

### Custom Task Types
To add custom task types:

1. **Implement in Go** (`src/engine-go/internal/background/server.go`):
```go
func customTask(ctx context.Context, args []interface{}) (interface{}, error) {
    // Your task implementation
    return result, nil
}
```

2. **Register task type**:
```go
func getTaskFunction(taskType string) (TaskFunc, error) {
    switch taskType {
    // ... existing cases ...
    case "custom_task":
        return customTask, nil
    default:
        return nil, fmt.Errorf("unknown task type: %s", taskType)
    }
}
```

3. **Add Python mapping** (`src/reaper/engine/core/background_tasks.py`):
```python
task_mappings = {
    # ... existing mappings ...
    "custom_task": "custom_task",
}
```

## Troubleshooting

### Server Not Starting
- Check if port 7071 is already in use
- Verify Go binary is built correctly
- Check logs for error messages

### Connection Issues
- Ensure Go task server is running
- Check firewall settings
- Verify environment variables

### Task Execution Failures
- Check Go server logs
- Verify task type is registered
- Ensure required dependencies are available

### Fallback to Python
If Go backend fails, the system automatically falls back to Python asyncio:
```python
# Force Python backend
background_manager = BackgroundTaskManager(use_go_backend=False)
```

## Migration Guide

### Existing Code
No changes required! The system automatically uses Go backend when available:

```python
# This code works with both Python and Go backends
from reaper.engine.core.background_tasks import background_manager

task_id = await background_manager.submit_task(my_function, args)
result = await background_manager.get_task_status(task_id)
```

### New Code
Leverage Go-specific features for optimal performance:

```python
# Use Go-specific task types for better performance
from reaper.engine.core.go_task_manager import submit_price_scan

task_id = await submit_price_scan(subscription_id, regions)
result = await bridge.wait_for_completion(task_id)
```
